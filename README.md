継続的に少しずつ育てていく3Dワールド制作プロジェクトです。制作環境は **Blender 4.x** を標準とします。

- ノイズを使った起伏のある浮遊島

## 実行方法
1. Blender 4.x を起動します。
2. **Scripting** ワークスペースを開きます。
3. `Blender/scripts/create_world.py` の内容をテキストエディターに読み込みます。
4. **Run Script** を押します。
5. 生成されたシーンを `Blender/world.blend` として保存します。
6. F12でレンダリングします。

スクリプトは現在のシーンを置き換えるため、既存の作業がある場合は先に保存してください。

## ディレクトリ
- `Blender/scripts/` — シーン生成・制作補助スクリプト
- `Models/` — モデル素材
- `Textures/` — テクスチャ
- `Screenshots/` — レンダリング画像
- `Progress/` — 日ごとの制作記録

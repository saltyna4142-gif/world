# Infinite 3D World

継続的に少しずつ育てていく3Dワールド制作プロジェクトです。制作環境は **Blender 4.x** を標準とします。

## 基本構成（Day 01）
最初の舞台として「浮遊島と小さな開拓地」を作ります。

- ノイズを使った起伏のある浮遊島
- 岩肌の島の下部
- 木造の小屋とテラコッタ色の屋根
- 針葉樹、岩、踏み石の小道
- 朝の柔らかな照明とプレゼン用カメラ

## 今回の追加（Day 02）
- 島の地形に沿うターコイズ色の小川
- 島の右手前の縁から流れ落ちる滝と薄い水のリボン
- 滝壺と水しぶきの小さな粒

## 実行方法
1. Blender 4.x を起動します。
2. **Scripting** ワークスペースを開きます。
3. `Blender/scripts/create_world.py` の内容をテキストエディターに読み込みます。
4. **Run Script** を押します。
5. 生成されたシーンを `Blender/world.blend` として保存します。
6. F12でレンダリングします。

スクリプトは現在のシーンを置き換えるため、既存の作業がある場合は先に保存してください。

## ディレクトリ
- `Blender/scripts/` — シーン生成・制作補助スクリプト
- `Models/` — モデル素材
- `Textures/` — テクスチャ
- `Screenshots/` — レンダリング画像
- `Progress/` — 日ごとの制作記録

## 進め方
毎回、既存の世界観と整合性を保ちながら小さな追加・改善を行い、制作記録を残します。

> 現時点では生成スクリプトと設計記録を保存しています。Blenderで実行して保存した `.blend` ファイルやレンダリング画像は、まだこのリポジトリには含まれていません。
